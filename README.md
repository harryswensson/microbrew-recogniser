## Microbrew recogniser in c



Created for the unit **uob-coms20007** **Programming Languages and Computation**.

Parses a string of [Microbrew](https://github.com/uob-coms20007/microbrew) and returns `True` if the string is a valid program and `False` if not.

## Usage



Compile using `make`

Run using `./recogniser.o "<INPUT STRING HERE>"`

Optional: Run using `./recogniser.o -debug "<INPUT>"` for a trace of where a parsing error occured
